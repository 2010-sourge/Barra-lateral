📌 README – Projeto Sidebar Responsiva com Efeito Glassmorphism

📖 Sobre o Projeto

Este projeto consiste em uma Sidebar (menu lateral) responsiva desenvolvida com HTML e CSS, utilizando o efeito moderno Glassmorphism, que cria uma aparência de vidro fosco sobre uma imagem de fundo.

O menu possui um design elegante e minimalista, sendo ideal para dashboards, sistemas administrativos, portfólios e sites modernos.

⸻

🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* Flexbox
* Responsividade
* Glassmorphism
* Ícones (Boxicons ou Font Awesome)

⸻

🎯 Funcionalidades

* ✅ Menu lateral fixo
* ✅ Fundo com efeito de vidro (Glassmorphism)
* ✅ Layout moderno
* ✅ Responsivo para diferentes tamanhos de tela
* ✅ Lista de navegação com ícones
* ✅ Área para redes sociais no rodapé
* ✅ Imagem de fundo em tela cheia

⸻

🖥️ Layout

O projeto apresenta:

* Logo no topo da sidebar
* Menu de navegação lateral
* Efeito transparente com desfoque
* Imagem ocupando todo o plano de fundo
* Ícones das redes sociais na parte inferior

⸻

📱 Responsividade

A interface foi desenvolvida para se adaptar a diferentes dispositivos, como:

* Desktop
* Notebook
* Tablet
* Smartphone

Em telas menores, a sidebar pode ser reduzida ou ajustada para melhor experiência do usuário.

⸻

🎨 Design

O visual utiliza o conceito de Glassmorphism, combinando:

* Transparência
* Desfoque (backdrop-filter)
* Bordas suaves
* Sombras discretas
* Cores modernas

Esse estilo proporciona uma interface elegante e agradável.

▶️ Como Executar

1. Faça o download ou clone o projeto.

git clone https://github.com/seu-usuario/sidebar-glassmorphism.git

2. Abra a pasta do projeto.
3. Execute o arquivo index.html em qualquer navegador.
